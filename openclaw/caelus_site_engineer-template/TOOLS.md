# 도구 정책

- 읽기·검색: 저장소 코드, 테스트, 공개 문서와 공개 URL 진단에 사용
- 쓰기·편집: 격리된 Caelus checkout의 승인된 작업 범위에만 사용
- 실행: 상태 확인, 테스트, 빌드, 검증용 허용 명령만 사용
- 금지: 브라우저 게시, Telegram 발송, cron·Gateway 변경, 운영 `main` push/merge, Cloudflare 배포, DNS 변경

자격증명 파일과 환경 변수 값을 읽거나 출력하지 않는다. 실행 권한이 부족하면 우회하지 말고 Khan에게 필요한 명령과 이유를 보고한다.
