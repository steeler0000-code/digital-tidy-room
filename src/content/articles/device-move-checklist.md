## 기기 이전은 복사가 아니라 검증까지 포함합니다

제조사의 이전 도구는 많은 데이터를 자동으로 옮기지만 모든 앱의 로그인 상태, 인증 수단, 오프라인 파일까지 동일하게 옮긴다고 가정해서는 안 됩니다. 새 기기에서 중요한 자료를 실제로 확인하기 전에는 이전이 끝난 것이 아닙니다.

## 이전 전 준비

1. 운영체제와 주요 앱을 지원되는 최신 상태로 업데이트합니다.
2. 최신 백업 시각과 오류 여부를 확인합니다.
3. 이메일, 클라우드와 비밀번호 관리자에 로그인할 수 있는지 확인합니다.
4. 2단계 인증 복구 코드와 인증 앱 이전 방법을 확인합니다.
5. 저장 공간이 충분한지 비교합니다.

사진과 파일이 클라우드에 있다는 표시만 보지 말고 대표 항목을 웹이나 다른 기기에서 열어봅니다.

## 자동 이전에서 빠지기 쉬운 항목

- 인증 앱과 보안 키 등록
- 메신저의 별도 백업이 필요한 대화
- 앱 내부에만 저장된 녹음, 그림, 게임 데이터
- 다운로드한 오프라인 지도와 음악
- 모바일 교통카드, 결제 수단과 전자 인증서
- 회사나 학교의 기기 관리 프로필

각 서비스의 공식 이전 안내를 확인하세요. 비밀번호나 인증 코드를 다른 사람에게 전달하지 않습니다.

## 이전 후 확인 순서

새 기기에서 통화와 메시지, 이메일, 사진, 파일, 캘린더, 연락처를 확인합니다. 중요한 앱은 단순히 아이콘이 있는지보다 로그인과 데이터 열람이 되는지 확인합니다.

인증 앱을 사용하는 계정 하나에 시험 로그인해 새 코드가 정상 작동하는지 확인합니다. 은행이나 회사 앱처럼 재등록이 필요한 서비스는 공식 절차를 따릅니다.

## 기존 기기 정리

새 기기를 며칠 사용한 뒤 누락이 없다고 판단하면 기존 기기에서 계정을 로그아웃하고 기기 찾기나 활성화 잠금 관련 설정을 공식 안내에 따라 해제합니다. 그다음 제조사가 제공하는 초기화 기능을 사용합니다.

판매나 양도 전에 메모리 카드, 유심, 케이스 안의 보관물도 확인합니다. 초기화 화면이 완료됐는지 직접 확인하고 거래 상대에게 비밀번호를 알려주지 않습니다.

## 초보자가 자주 하는 실수

- 백업 완료 표시만 보고 복원 가능한지 시험하지 않습니다.
- 인증 앱 이전 전에 기존 기기를 지웁니다.
- 새 기기의 저장 공간이 부족한데도 이전을 시작합니다.
- 기존 기기에서 계정과 기기 찾기 설정을 정리하지 않습니다.

## 체크리스트

- [ ] 최신 백업과 대표 파일을 확인했습니다.
- [ ] 계정 비밀번호와 복구 수단을 준비했습니다.
- [ ] 인증 앱과 메신저의 별도 이전 절차를 확인했습니다.
- [ ] 새 기기에서 중요한 자료와 로그인을 직접 시험했습니다.
- [ ] 며칠 사용한 뒤 기존 기기를 정리했습니다.
- [ ] 공식 절차로 로그아웃과 초기화를 완료했습니다.

## 정리

기기 이전은 복사 버튼을 누르는 순간이 아니라 새 기기에서 중요한 자료와 계정이 작동함을 확인할 때 끝납니다. 백업, 복구 수단, 예외 앱, 검증, 기존 기기 초기화의 순서를 지키면 급하게 처분한 뒤 자료를 찾는 위험을 줄일 수 있습니다.
