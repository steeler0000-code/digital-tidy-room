## 두 도구는 서로 다른 문제를 해결합니다

비밀번호 관리자는 많은 계정의 서로 다른 비밀번호를 기억해야 하는 문제를 줄입니다. 2단계 인증은 비밀번호가 알려진 뒤에도 추가 인증을 요구해 계정 접근을 어렵게 합니다. 하나를 켰다고 다른 하나가 필요 없어지는 것은 아닙니다.

## 비밀번호 관리자의 역할

신뢰할 수 있는 비밀번호 관리자는 각 서비스에 길고 고유한 비밀번호를 생성하고 암호화된 저장소에 보관합니다. 사용자는 관리자 자체에 들어가는 주 비밀번호를 기억합니다.

처음에는 이메일, 금융, 클라우드 저장소처럼 다른 계정의 복구에 영향을 주는 중요 계정부터 옮기세요. 기존 비밀번호를 바꿀 때 서비스마다 하나씩 진행하고 로그인이 정상인지 확인합니다.

## 2단계 인증의 역할

2단계 인증은 비밀번호 외에 인증 앱, 보안 키, 기기 알림이나 일회용 코드 등을 요구할 수 있습니다. 가능한 방식은 서비스마다 다릅니다. 문자 메시지 인증만 제공하는 경우도 있지만, 더 강한 방식을 지원한다면 공식 안내에서 선택지를 비교하세요.

중요 계정부터 활성화하고 복구 코드를 안전한 위치에 보관합니다. 휴대전화를 바꾸거나 잃어버렸을 때 사용할 복구 절차도 함께 확인해야 합니다.

## 주 비밀번호와 복구 수단

주 비밀번호는 다른 서비스에서 사용하지 않는 길고 고유한 문구로 만듭니다. 관리자 계정 자체에도 2단계 인증을 켤 수 있다면 고려하세요.

복구 코드를 화면 캡처해 같은 휴대전화에만 두면 기기를 잃었을 때 함께 접근할 수 없습니다. 종이, 암호화된 별도 저장소 등 자신의 위험에 맞는 분리 방법을 정합니다.

## 초보자가 자주 하는 실수

- 기존 비밀번호를 관리자에 저장만 하고 서비스별 반복 비밀번호를 바꾸지 않습니다.
- 자동 입력 화면을 확인하지 않아 가짜 사이트에 정보를 넣습니다.
- 2단계 인증을 켠 뒤 복구 코드를 저장하지 않습니다.
- 가족이나 동료에게 인증 코드를 전달합니다. 정상적인 지원 담당자가 비밀번호나 인증 코드를 요구해서는 안 됩니다.

## 적용 체크리스트

- [ ] 신뢰할 수 있는 비밀번호 관리자를 선택했습니다.
- [ ] 주 비밀번호를 다른 곳에서 재사용하지 않습니다.
- [ ] 중요 계정부터 고유한 비밀번호로 바꿨습니다.
- [ ] 이메일과 클라우드 계정에 2단계 인증을 설정했습니다.
- [ ] 복구 코드를 로그인 기기와 분리해 보관했습니다.
- [ ] 자동 입력 전 사이트 주소를 확인합니다.

## 정리

비밀번호 관리자는 반복 비밀번호를 줄이고, 2단계 인증은 비밀번호가 노출된 뒤의 방어선을 더합니다. 중요 계정부터 천천히 적용하고 주 비밀번호, 복구 코드와 기기 교체 상황까지 함께 준비하세요.
